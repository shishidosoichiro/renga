# make_slug が長い日本語タイトルで単語の途中で途切れる

## 問題

`make_slug`（`src/issue.rs`）は Unicode 文字単位で 30 文字にカットするだけで、
日本語には分かち書きの区切りがないため複合語・文節の途中でぶった切られる。
本 issue 自身のファイル名（`214-make-slug-が長い日本語タイトルで単語の途中で途切れ.md`）が
末尾の「る」が欠落した実例になっている。

## 前提

slug はあくまで人間可読のラベルで、一意性は `N-` の ID 部分が担保している。
実害は「読みにくい」レベルに留まり、正確性やデータ整合性の問題ではない。

## 対応案

形態素解析（MeCab/Sudachi 等)を依存に追加するのはやりすぎ。素朴に直せる範囲で:

- 区切り文字（スペース・記号）の直前で切る best-effort（区切りが30文字以内に
  無ければ従来通り文字数カットにフォールバック）
- または上限を 30→40 程度に伸ばして頻度を下げる

どちらか、または両方の組み合わせで検討する。
