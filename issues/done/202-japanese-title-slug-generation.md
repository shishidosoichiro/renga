# renga create で日本語タイトルからのスラグ自動生成が機能しない

## 問題

`renga create` で `--slug` を指定しない場合、日本語タイトルからスラグを自動生成しようとするが、日本語が除去されて意味のない断片（`issue`・`10` 等）しか残らない。

## 再現手順

```sh
renga create "エージェント体制の必要性レビュー：10エージェント構成が適切かを評価する"
# → 451-10.md（「10」しか残らない）

renga create "実装系エージェントの作業内で動的サブエージェントを活用するガイドラインを定義する"
# → 457-issue.md（無意味な断片）
```

## 期待する挙動

日本語タイトルの場合、タイトル全体をそのままスラグとして使う、またはユーザーに `--slug` 指定を促すエラー・警告を出す。

## 回避策

`--slug` を明示的に指定する。
