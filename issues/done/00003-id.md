# ID のゼロ埋めをなくす（または桁数を設定可能にする）

現在 fbim は5桁のゼロ埋め ID（00001 等）を生成する。ゼロ埋めの目的は ls でのファイル並び順だが、fbim がツールとして数値ソートを担保するなら不要になる。GitHub・Linear・JIRA のような主要 issue トラッカーもゼロ埋めをしない。プロジェクト横断で issues を統合する際に、既存の4桁・5桁の混在も問題になっている。対応案: (A) ゼロ埋めなしの整数 ID にする (B) 桁数を設定可能にする。(A) を推奨。
